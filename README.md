# Верификация диктора

Сервис сравнивает два аудиофайла и определяет, принадлежат ли они одному и тому же
голосу. Модель — ECAPA-TDNN (`speechbrain/spkrec-ecapa-voxceleb`), интерфейс — Gradio
(`app.py`). Валидация — в `validation.ipynb`.

## Что мы делали (простыми словами)

1. **Проверили, что сервис вообще работает правильно.** Взяли пары чистых записей голоса,
   часть из них — один и тот же человек, часть — разные люди, и посмотрели, насколько
   хорошо модель их различает.
2. **Испортили звук и проверили снова.** Понизили качество записи (как в плохой телефонной
   связи) и добавили треск трёх уровней — слабый, средний, сильный — чтобы понять, насколько
   сильно шум сбивает модель с толку.
3. **Подобрали порог принятия решения.** Не под один конкретный уровень шума, а сразу под
   смесь чистых и зашумлённых записей — чтобы порог одинаково хорошо работал в любых условиях,
   а не только в лучшем случае.
4. **Проверили на совсем других записях.** Взяли другой датасет (CN-Celeb) — с реальным, не
   искусственным шумом и на другом языке — чтобы понять, не "подогнались" ли мы под свои же
   тестовые условия и как модель поведёт себя на записях, которых никогда не видела.

## Установка и запуск

```bash
pip install -r requirements.txt
python app.py
```

## Методология валидации

| Уровень | Что делали |
|---|---|
| 1. Baseline | EER на чистых парах VoxCeleb1-O (`veri_test2.txt`), sanity check пайплайна |
| 2. Деградация | Downsample 16→8кГц + синтетический треск (light/medium/strong) на тех же парах |
| 3. Калибровка threshold | EER на смешанном пуле (250 clean + 250 light + 250 medium + 250 strong) |
| 4. Обобщаемость | Проверка откалиброванного threshold на CN-Celeb (реальный "полевой" шум, out-of-distribution) |

## Результаты

| Уровень | EER | AUC |
|---|---|---|
| Чистые (VoxCeleb1) | 1.20% | 0.9996 |
| Light (8кГц + лёгкий треск) | 2.40% | 0.9976 |
| Medium (8кГц + средний треск) | 1.81% | 0.9966 |
| Strong (8кГц + сильный треск) | 3.81% | 0.9937 |
| **CN-Celeb (out-of-distribution)** | **15.20%** | **0.9014** |

**Итоговый threshold: `0.3088`** (откалиброван на смешанном пуле — Уровень 3, используется в `app.py`).

## Выводы

- Модель устойчива к синтетической деградации (даунсемпл + треск) — EER растёт умеренно,
  AUC остаётся выше 0.99 даже при сильном шуме.
- **Резкое падение качества на CN-Celeb** (EER 15.2% против 1.2% на чистом VoxCeleb) —
  реальный "полевой" шум ощутимо сложнее для модели, чем наша синтетическая имитация.
  Учитывая иную природу аудиофайлов (китайский язык), модель показывает себя робастно.
